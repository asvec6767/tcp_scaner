# tcp_scaner

Встраиваемый TCP Connect-сканер на Go 1.25.5. Только стандартная библиотека, без CLI, HTTP и SYN/UDP.

## Использование

```go
package main

import (
	"context"
	"fmt"
	"log"
	"time"

	portscan "github.com/asvec6767/tcp_scaner"
)

func main() {
	scanner, err := portscan.New(portscan.Config{
		Concurrency:    32,
		ConnectTimeout: 500 * time.Millisecond,
	})
	if err != nil {
		log.Fatal(err)
	}
	ports, err := portscan.Ports(22, 80, 443)
	if err != nil {
		log.Fatal(err)
	}
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	results, err := scanner.Scan(ctx, []string{"127.0.0.1", "::1"}, ports)
	if err != nil {
		log.Fatal(err)
	}
	for result := range results {
		fmt.Printf("%s:%d %s\n", result.Host, result.Port, result.State)
	}
}
```

## Публичный API

- [New(Config)](portscan.go:51) создаёт сканер; конкурентность и таймаут подключения строго положительные.
- [Ports, Range, Merge](portscan.go:96) создают списки, включительные диапазоны и их объединения. Порты — 1–65535; дубликаты удаляются, неверные значения и обратные диапазоны возвращают ошибку.
- [Scanner.Scan](portscan.go:66) принимает контекст, хосты и набор портов; возвращает канал результатов и ошибку валидации. Пустые цели/порты, некорректные хосты, отсутствующий или отменённый контекст запрещены.
- [Result](portscan.go:20) содержит исходный хост, фактический IP, порт, состояние, длительность (DNS + подключение) и исходную ошибку. Состояния: open, closed, timeout, unreachable, canceled, error. Ошибки DNS/подключений приходят в результатах.

## Поведение

- Поддерживаются IPv4, IPv6 без скобок и ASCII DNS. URL, CIDR, хост с портом, IPv6 zone, Unicode и подчёркивания не поддерживаются.
- Хосты нормализуются и дедуплицируются; результат сохраняет исходную строку первого появления. DNS и выбор адреса выполняет стандартный dialer, каждый IP имени отдельно не сканируется.
- Успешное соединение сразу закрывается. При ошибке IP может отсутствовать. Внешняя отмена/дедлайн дают canceled, собственный таймаут подключения — timeout.
- Лимит конкурентности действует на вызов; сканер допускает повторное и параллельное использование. Входы копируются, очереди ограничены; медленный читатель создаёт обратное давление.
- Без отмены возвращается один результат на уникальную пару хост/порт, порядок не гарантируется. При отмене новые проверки прекращаются, активные подключения отменяются; канал закрывается после завершения работников, поток может быть неполным.
- **При досрочном прекращении чтения обязательно отмените контекст.**
