# tcp_scaner

Требуется Go 1.25.5; используются только пакеты стандартной библиотеки.

## Текущий этап

Реализованы внутренние пакеты `internal/tcpcheck` и `internal/targets`,
не публичный сканер. Пула, каналов результатов и пакета портов пока нет.

### Проверка целей

`targets.Normalize(hosts []string) ([]targets.Target, error)` синхронно
проверяет и нормализует непустой список, удаляет дубликаты и сохраняет порядок.
При ошибке возвращает `nil` и сообщение с индексом и исходной целью.
Входной список не меняется; DNS-запросов и подключений нет.

`Target.Host` — точная исходная строка первого появления (с пробелами),
`Target.Address` — хост для подключения: IP в канонической форме или DNS
в нижнем регистре без конечной точки, после `TrimSpace`.
Будущий корневой сканер передаст `Address` в `tcpcheck.Check`, но публичный
`Result.Host` возьмёт из `Target.Host`. Сам `tcpcheck` сохраняет переданный хост.

Допускаются IPv4, IPv6 без скобок и ASCII DNS, включая однометочные и готовые
punycode-имена. IPv4-mapped IPv6 приводится к IPv4 и дедуплицируется с ним.
IPv6 zone, URL, порт, CIDR, Unicode и подчёркивания запрещены.
Полностью числовые строки с точками или без них должны быть строгим IPv4:
`01.2.3.4`, `1.2.3`, `123` и `1.2.3.4.` — ошибки, а не DNS-имена.
DNS-метки: 1–63 ASCII-байта, буквы/цифры/дефис, без дефиса по краям;
длина имени без конечной точки — до 253 байт. Существование DNS не проверяется.

### Одиночная TCP-проверка

`tcpcheck.Check(ctx, host, port, timeout) tcpcheck.Result` выполняет одну
TCP Connect-проверку. Вызывающий код передаёт проверенный хост без порта
(IPv6 — без скобок), порт 1–65535 и строго положительный таймаут.

Результат содержит исходный `Host`, `Port`, фактический `IP`, `State`,
`Duration` и исходную `Err`. Состояния: `Open`, `Closed`, `Timeout`,
`Unreachable`, `Canceled`, `Error` со строковыми значениями из ADR.
Успешное соединение сразу закрывается; ошибка закрытия не меняет `Open`.
Длительность включает весь вызов подключения, включая DNS, но не закрытие.

DNS и выбор адреса/fallback выполняет стандартный `net.Dialer.DialContext`.
IP берётся только из удалённого адреса успешного TCP-соединения; при ошибке
отсутствует. Отмена или дедлайн внешнего контекста при неуспешной проверке
дают `Canceled`, собственный таймаут подключения — `Timeout`.

## Проверки

```sh
gofmt -w internal/targets internal/tcpcheck
go vet ./...
go test -race ./...
```

Тесты проверяют только экспортируемый API из внешнего тестового пакета:
табличные сценарии валидации целей, границы длины, нормализацию,
дедупликацию, порядок и сохранение исходного хоста; для `tcpcheck` —
локальное соединение, его закрытие, IP, длительность, отмену и дедлайн
внешнего контекста. IPv6-тест пропускается, если loopback недоступен.
Внешние сети и подмена внутренних зависимостей не используются.
Системные ошибки, DNS-ошибки и собственный таймаут не покрыты отдельными
детерминированными сценариями: текущий API не позволяет воспроизвести их
без зависимости от окружения или вмешательства во внутреннюю реализацию.
